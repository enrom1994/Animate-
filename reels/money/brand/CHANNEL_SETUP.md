# Ten Years On: YouTube Studio setup checklist

Menu names are as of late 2026 and YouTube moves them around; if one is missing, search Studio's settings for the item.

## 1. Customization → Profile
- **Name:** Ten Years On
- **Handle:** @TenYearsOnShorts
- **Description** (paste):
```
Two neighbors. Same paycheck. Different choices.

Every week, Max and Theo make one everyday money choice: a car, a card, a phone plan, a raise. Then we jump ahead and
show what it cost. Every number on screen is sourced, and the sources are in each video's pinned comment.

Animated, short, and never "you will earn X". Education, not financial advice.
```
- **Links:** none needed yet. **Contact email:** optional (a separate address is better than your personal one).

## 2. Customization → Branding
- **Picture:** `profile_800.png`
- **Banner:** `banner_2048x1152.png` (check the preview: the title and both faces must sit inside the "all devices" area)
- **Video watermark:** skip for Shorts

## 3. Settings → Channel
- **Basic info:** country **United States**; keywords: `personal finance, money tips, car loan, buy now pay later, assets and liabilities, budgeting, investing basics, money explained`
- **Advanced settings → Audience:** **No, set this channel as not made for kids**

## 4. Settings → Upload defaults
- **Basic info → Description** (each video's own text goes above it):
```
Education, not financial advice.
New money choices every week · @TenYearsOnShorts
```
- **Visibility:** Private or Unlisted, so you check each video before publishing
- **Advanced settings:** category **Education**; video language **English**; caption certificate: none needed; comments
  on (hold potentially inappropriate comments for review)

## 5. Settings → Feature eligibility
- Verify the phone number: it unlocks the intermediate features (links in descriptions, longer videos, custom thumbnails later).

## 6. Each upload
- Title, description, hashtags, tags and cover frame from the episode's `UPLOAD.md`
- **Audience:** not made for kids
- **Altered or synthetic content:** read the question as worded; the narration is a synthetic (Kokoro) voice, so answer yes
  if it asks about synthetic voices
- **After publishing:** post the pinned comment from `UPLOAD.md` and pin it

## Order
Episode 1 first, then about a week before episodes 2 and 3. Episode 2 waits until its late-fee figures are confirmed on
the lenders' own pages.
